How alerts work

  • A GitHub Actions job runs twice a day (and can be started manually). It reads the official sources above and keeps only items matching the rules in pharma-monitor/config.json.
  • When something new is found, the job opens a GitHub issue labelled regulatory-update; GitHub e-mails it to you. Optional direct e-mail can be switched on with SMTP secrets (see README).
  • Law changes: for 18 key laws (e.g. 362/2011, 363/2011, 39/2007) every new consolidated wording is compared with the previous one, provision by provision, with removed and added text highlighted.
  • Amending acts: new acts in the Collection of Laws are read in full; the exact amendment points for key laws are shown, even inside omnibus acts.
  • Reimbursement list: each monthly list of categorised medicines is compared with the previous month – added, removed and repriced medicines by ŠÚKL code.
  • Draft laws: new drafts and every change of stage (comment procedure, government, Parliament) are tracked, with the comment deadline.
Monitoring aid only, not legal advice. Always rely on the official published text. Data: Slov-Lex (MS SR), ŠÚKL, ÚŠKVBL, MZ SR, ŠVPS SR, EUR-Lex (Publications Office of the EU), EMA.
